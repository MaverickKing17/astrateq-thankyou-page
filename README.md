## Installation

1. Clone the repo:

```bash
git clone https://github.com/yourusername/astrateq-thankyou-page.git
```

2. Navigate to the project directory:

```bash
cd astrateq-thankyou-page
```

3. Install dependencies (if using Node/Tailwind build):

```bash
npm install
```

4. Run the local server to preview:

```bash
npm run dev
```
